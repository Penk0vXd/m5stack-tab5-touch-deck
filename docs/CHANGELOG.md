# История на промените (Changelog)

Всички забележителни промени по този проект ще бъдат документирани в този файл.

## [Unreleased] - Първоначален прототип

### Добавено
- Базова инфраструктура за ESP-IDF 5.5.5.
- Интеграция с дисплея и тъчскрийна на M5Stack Tab5 (ESP32-P4).
- Графичен интерфейс базиран на LVGL 9.5.0 (разделителна способност 1280x720).
- Базови екрани: Home, Git, Media.
- USB HID поддръжка (клавиатура и consumer control) чрез TinyUSB и `esp_tinyusb`.
- Python Host Agent за Windows за изпращане на телеметрия и изпълнение на разрешени команди (`config.toml`).
- Механизъм за конфигурация чрез `config.json`, съхраняван в SPIFFS.
- Относителен volume slider, звуков feedback и поддръжка на BMI270 за жестове.

### Известни проблеми
- Качването (Upload) на конфигурацията не е атомарно при загуба на захранване.
- Хардуерните тестове все още не покриват всички компоненти на 100%.
