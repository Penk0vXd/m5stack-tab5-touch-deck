# Структура на проекта

Този документ описва организацията на директориите и файловете в хранилището на проекта Tab5 Touch Deck.

## Основна структура

```text
tab5-touch-deck/
├── docs/             # Документация на проекта (Markdown файлове)
├── firmware/         # C/C++ изходен код за ESP32-P4 (ESP-IDF)
│   ├── main/         # Основна логика на приложението
│   │   ├── ui/       # LVGL екрани и компоненти
│   │   ├── usb/      # USB HID и TinyUSB конфигурация
│   │   └── core/     # Инициализация и системни задачи
│   ├── components/   # Локални ESP-IDF компоненти (напр. модифициран BSP)
│   └── CMakeLists.txt
├── host-agent/       # Python агент за компютъра
│   ├── agent.py      # Основен скрипт на агента
│   ├── config.toml   # Конфигурация за разрешени команди
│   └── requirements.txt
├── editor/           # Локален визуален редактор без build зависимости
│   ├── index.html
│   ├── styles.css
│   └── app.js
├── scripts/          # Помощни скриптове
├── storage/          # Файлове за вътрешната памет (SPIFFS)
│   └── config.json   # Конфигурация на екраните и бутоните
└── README.md         # Основен документ с инструкции
```

## Детайли по папките

### `firmware/`
Съдържа кода, който се компилира и записва (flash) на ESP32-P4 микроконтролера. Проектът използва ESP-IDF v5.5.5. Папката `main` съдържа потребителската логика, разделена на модули за графичен интерфейс (LVGL), USB комуникация (TinyUSB) и системно управление.

### `host-agent/`
Python приложение, което работи на свързания компютър. То слуша за HID команди от устройството, събира телеметрия (CPU, RAM, дисково пространство) и изпълнява команди, които са изрично дефинирани в `config.toml`.

### `editor/`
Dependency-free локално web приложение за preview, drag-and-drop подреждане,
Inspector редакция, validation и export на UI v2 конфигурации.

### `scripts/`
Скриптове за автоматизация на задачи по време на разработка.

### `storage/`
Файлове, които се записват във файловата система (SPIFFS) на устройството. Основният файл е `config.json`, който дефинира подредбата на екраните, макросите и външния вид на бутоните.
