# Цел и обхват

[Индекс](README.md) · [Състояние](CURRENT_STATE.md)

Tab5 Touch Deck превръща M5Stack Tab5 в програмируема USB конзола за настолен компютър. Чести клавишни комбинации, медийни команди и избрани локални операции се извикват с докосване. Екранът може едновременно да показва състоянието на компютъра.

Предназначен е за разработчик или потребител, който може да редактира JSON/TOML и иска физически контролен панел за редактор, терминал и мултимедия. Интерфейсът не е редактор за конфигурацията: тя се променя на компютъра.

| Част | Отговорност | Необходима |
|---|---|---|
| ESP32-P4 firmware | UI, клавиатура, USB transport, SPIFFS | Да |
| `storage/config.json` | Страници, действия и настройки | За персонализирания deck; има fallback |
| Python агент | Whitelist команди, telemetry, Windows profiles, upload | Само за тези функции |
| `host-agent/config.toml` | USB selector и разрешени команди | За агента |
| ESP-IDF | Build/flash | При разработка |

## Workflow

1. Редактирайте JSON и build-нете firmware със SPIFFS image.
2. Flash-нете по USB-C в download mode. След reset firmware се представя като две HID interfaces.
3. Boot инициализира дисплей/touch, SPIFFS и JSON модел. UI показва първата страница — Home в доставения файл.
4. Shortcut влиза в HID queue и се изпълнява в активното приложение на компютъра.
5. `agent` бутон изпраща име. Python го търси в whitelist, стартира фиксирана команда и връща status.
6. Агентът изпраща CPU/RAM/disk проценти и, на Windows, window title. UI обновява стойности и избира съвпадаща страница.
7. Нова конфигурация може да бъде изпратена по USB без firmware flash — с ограниченията в [CONFIGURATION](CONFIGURATION.md).

## Локална работа и мрежа

Keyboard/consumer работят без Python. Телеметрията и `agent` действията изискват агент. UI, `goto_page`, звуците и жестовете са на Tab5.

Приложението не отваря socket, няма HTTP порт или REST API. USB raw HID е собственият протокол. Интернет е нужен за първоначалното изтегляне на инструменти и зависимости. Git/Docker командите могат да ползват мрежа чрез host инструментите и credentials на потребителя.

Не са реализирани Wi-Fi pairing, BLE keyboard, camera view, микрофонен запис, SD конфигурация, battery UI, OTA или cloud sync. Наличието на BSP драйвер не означава интегрирана функция.
