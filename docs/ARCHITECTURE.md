# Архитектура

Този документ описва софтуерната архитектура на системата Tab5 Touch Deck, включително основните модули и потока на данни.

## Основни модули

1. **UI (LVGL)**: Управлява визуализацията на екрана. Четейки конфигурацията, генерира бутони, слайдъри и плочки за телеметрия. Прихваща докосвания (touch events) и ги препраща към логическия слой.
2. **Config (SPIFFS JSON)**: Модул за съхранение в енергонезависимата памет. Зарежда потребителските интерфейси, дефиниции на бутони и макроси от JSON файлове, съхранени във файловата система SPIFFS.
3. **USB HID (TinyUSB)**: Управлява комуникацията с хост компютъра чрез стандартни USB класове (Keyboard, Consumer Control) за директно въвеждане и Raw HID за двупосочна връзка с агента.
4. **Host Agent (Python)**: Програма, работеща на компютъра (host). Слуша за команди през Raw HID, изпълнява разрешени скриптове (чрез whitelist) и периодично изпраща телеметрия (CPU/RAM/Disk) обратно към устройството.

## Поток на данни и събития

```mermaid
flowchart TD
    subgraph Host[Компютър / Host]
        PythonAgent[Host Agent (Python, psutil)]
        HIDAPI[HID API]
        OS[Операционна система]
    end

    subgraph Tab5[M5Stack Tab5 (ESP32-P4)]
        UI[UI / LVGL]
        Config[Config / SPIFFS]
        USB_Stack[USB HID / TinyUSB]
        Hardware[Сензорен екран / Бутони]
    end

    Hardware -->|Докосване| UI
    Config -->|JSON конфигурация| UI
    UI -->|Генериране на HID събитие| USB_Stack
    USB_Stack -->|Стандартни клавиши/Медия| OS
    USB_Stack <-->|Raw HID (JSON/Телеметрия/Команди)| HIDAPI
    HIDAPI <--> PythonAgent
    PythonAgent -->|Събиране на статус| OS
    PythonAgent -->|Изпълнение на команди| OS
```

Когато потребителят натисне бутон на екрана на Tab5, UI модулът разпознава събитието, определя съответното действие от конфигурацията и го изпраща към USB модула. Ако е стандартен клавиш, той се праща директно на ОС. Ако е специална локална команда, тя се изпраща като съобщение през Raw HID към хост агента, който я изпълнява. Периодично, хост агентът извлича телеметрия и я праща към екрана за обновяване на плочките (tiles).
